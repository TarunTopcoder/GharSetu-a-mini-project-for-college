# GharSetu

**Find Your Space. Find Your Home.**

GharSetu is a frontend-only Indian rental marketplace demo built with React, Vite, Tailwind CSS, React Router, and Lucide icons. Listings, demo accounts, favorites, viewed homes, and owner changes are stored locally in the browser.

## Run locally

Install [Node.js](https://nodejs.org/) first. From the project directory, run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Demo accounts

- Tenant: `tenant@gharsetu.demo` / `Demo123`
- Owner: `owner@gharsetu.demo` / `Demo123`

Authentication and contact/visit actions are demonstrations only. No backend or real booking is used.

## Main features

- Search and filter 40 sample listings by city, type, bedrooms, rent, furnishing, bathrooms, and parking.
- Browse property pages, save homes, and view local demo contact/visit flows.
- Register or log in with demo accounts and manage tenant favorites and activity.
- Add, edit, and remove owner listings; new listings appear in public search.
- Responsive homepage, city discovery, About, and Contact pages.
